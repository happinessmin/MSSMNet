# MSSMNet

**MSSMNet: A Multi-Scale State Space Model Network for Semantic Segmentation of Remote Sensing Images**

This repository will host the official implementation of MSSMNet. The code and documentation are currently being organized and are not yet ready for release.

We plan to add the model implementation, environment setup instructions, data preparation guidance, training and evaluation scripts, and information needed to reproduce the reported experiments.
